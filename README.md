# 🏦 Banksit App

Banksit is a simple banking web application that allows users to **log in**, **transfer money**, and **request loans** between accounts. It is designed for educational and demonstration purposes. App was created as part of JavaScript Udemy course.

---

## 🚀 Features

- 💳 Log in with a custom username and password
- 🔁 Transfer money to other users
- 💸 Request loans
- 🧾 Track transaction history

---

## 🔐 Login Instructions

To log in:

- **Username:** First letter of the first name + first letter of last name (all lowercase)
  - Example: `John Smith` → `js`
- **Password:** Stored inside the account objects in the JavaScript (`.js`) file

> Open the JavaScript source code to view the list of sample accounts and their passwords.

---

## 🧪 Sample Accounts

Example user data (name, balance, password, etc.) is stored in the `accounts` array inside the JavaScript file. Use these to test login and features.

## ▶️ How to Run the App Locally

1. Make sure you have **Node.js** and **npm** installed.
2. Install `live-server` globally (if not already installed):

   ```bash
   npm install -g live-server
   ```
