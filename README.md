# 🏦 Bankist App

**Bankist** is a modern, single-page banking interface built entirely with **vanilla JavaScript**. It allows users to log in to a mock account, view transactions, transfer funds, request loans, and close their account — all within a clean, dynamic UI.

This project was developed during the  
**[The Complete JavaScript Course 2023](https://www.udemy.com/course/the-complete-javascript-course/)**  
by **Jonas Schmedtmann** on **Udemy**.

---

## 🚀 Features

- 🔐 Login using a username and PIN
- 📄 View and sort transaction history
- 💸 Transfer money to other accounts
- 🧾 Request loans with simple logic
- ❌ Close your account
- ⏱ Auto logout after inactivity (security feature)
- 🧠 All functionality built with pure JavaScript (no frameworks)
